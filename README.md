# Parcel Note

구매한 의류와 보관 재고를 한 박스에 담아 보내는 상황을 확인하는 독립 정적 웹 데모입니다. 일본·대만·홍콩·미국 노선, 한국어·영어를 제공합니다. 상품, 재고 수량, 중량 및 운임은 모두 가상입니다.

`index.html`을 열면 실행됩니다. 외부 스크립트, API, 추적, 데이터베이스 및 로그인이 없습니다. `node --test tests/estimator.test.mjs`로 계산과 공유 링크를 검사합니다.

GitHub Pages에서는 main 브랜치의 루트를 게시할 수 있습니다. 메일·웹뷰는 같은 웹 주소를 사용합니다. 견적 링크의 fragment는 버전, 도착국, 언어, 탭, 의류별 수량, 선택한 박스 크기를 담습니다. 사용자 식별자나 고객별 실제 재고를 URL에 넣지 않습니다. 공유 버튼은 HTTPS 게시 환경에서 동작하며 클립보드가 차단되면 선택 가능한 주소를 표시합니다.

고객 운영 전에는 회사 서비스에서 본인 인증과 주문·재고 소유권을 검사하는 조회 경로, 입고 전/보관 중 중복 제거, 현재 고객가와 박스별 실측·과금 규칙, 견적 만료 및 실제 청구액 대사가 필요합니다. 실제 고객 정보는 개인 저장소나 정적 번들에 넣지 않습니다.
